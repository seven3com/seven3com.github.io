取得する情報と目的

本人のGoogle OAuth同意に基づき、対象チャンネルの確認、動画ID・公開状態・タイトル・公開日時・尺、 再生数や再生時間、維持率、インプレッション/CTRなどの公式API統計を取得し、所有者による実績確認に利用します。 視聴者の氏名・メールアドレス等の個人別情報は収集しません。 公開動画一覧への保存/共有対象は公開動画だけです。非公開/限定公開動画の情報はその一覧へ出しません。

認証情報と保存・共有

OAuthクライアント情報とトークンは所有者PCのGit管理外のアクセス制限付きフォルダに保存します。 OAuth秘密情報をGitHub、案内サイト、広告事業者へ送信しません。 利用者の指定により、必要最小限の集約統計をprivate GitHub保管先へ保存し、本人が指定するAI支援の分析で参照できます。 最近の公開動画一覧は、公開動画のID・URL・タイトル・公開日時・確認時刻を別のprivateファイルへ保存できます。 第三者への販売や広告目的での利用は行いません。

保持・更新・削除

Data API由来のメタデータは少なくとも30日ごとに更新または削除します。 Analytics/Reporting統計は許可された目的に必要な期間保持し、少なくとも30日ごとにアクセス権と動画の存在を確認します。 PCが長期間停止している場合は、自動更新が行われていると扱いません。 削除依頼は上記連絡先へお送りください。依頼から7日以内に、現行ファイルだけでなく管理下のGit履歴・cloneも対象に対応します。 Googleアカウントの接続管理から権限を取り消せます。取り消し後は再同意するまで取得を停止します。

Google APIと案内サイト

Google APIから受け取る情報の使用・他アプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。 案内サイト自体にはログイン、アクセス解析、広告、Cookieを使う独自機能を設けません。 GitHub Pagesを利用する場合、GitHubがセキュリティ目的でアクセス元IPを記録します。GitHub Privacy Statementもご確認ください。
