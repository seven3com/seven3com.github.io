プライバシーポリシー

更新日：2026年11月11日

取得・利用する情報

所有者のGoogle OAuth同意に基づき、YouTubeチャンネルや動画の情報、再生数・再生時間・視聴維持率・インプレッションなどの統計を読み取り、動画の実績確認と分析に使用します。視聴者の氏名やメールアドレスなど、個人別の情報を収集する機能はありません。

保存・共有

認証情報は所有者が管理するアクセス制限付き環境に保存します。必要な動画情報や統計は、本人管理の非公開保管先に保存し、本人が利用する分析支援ツールで参照する場合があります。認証情報や非公開動画の情報をこの案内サイトに掲載せず、広告目的で販売しません。

保持・削除・権限取消

保存データは利用目的に必要な範囲で保持し、Google・YouTubeのAPIポリシーに従って更新・削除の対象とします。データの確認や削除のご希望は下記メールへお問い合わせください。Googleアカウントの連携管理から権限を取り消すこともできます。

Google APIのデータ利用はGoogle API Services User Data PolicyおよびYouTube API Services Developer Policiesに従います。
