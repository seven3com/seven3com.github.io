プライバシーポリシー

更新日：2026年11月11日

取得する情報・目的

チャンネル所有者によるGoogle OAuth同意に基づき、接続先チャンネルの確認、承認済み動画の投稿、サムネイル設定、投稿した動画のID・タイトル・公開状態・処理状況等の確認に必要なYouTube APIデータを扱います。動画ごとの事前承認、重複投稿防止、実行結果の確認、障害時の再開のために利用します。視聴者の個人情報を収集する機能はありません。

保存先と第三者への提供

動画素材とアップロード用OAuth認証情報は、所有者の管理するNASのアクセス制限付き領域で扱います。承認記録、動画のタイトル・説明文、実行状態、動画ID、APIの読戻し結果などは、必要な範囲で所有者の非公開GitHubリポジトリとNASの運用記録に保存されます。非公開動画の情報やOAuthトークンを、この公開案内サイトに掲載しません。

データはGoogle/YouTube APIと上記の保管サービスを使って処理されます。広告目的での提供や販売は行いません。本サイトに独自のアクセス解析・広告・ログイン機能は設けていません。サイト配信を担うGitHubのデータ取扱いはGitHub Privacy Statementをご確認ください。

保持・訂正・削除

認可がある間、重複投稿を防ぐための承認・処理履歴と、投稿結果の確認に必要な情報を保持します。YouTube APIから取得したメタデータは、APIのポリシーに基づき、必要な更新または削除の対象とします。過去の記録が常に最新のYouTube状態と一致するとは限らないため、表示時には確認時点を区別します。

保存データの確認・削除希望は連絡先メールへお知らせください。本人確認後、NAS・非公開GitHub等の管理下の保存先を確認し、YouTube APIポリシーが定める期限に従って対応します。権限を取り消した場合はAPIへのアクセスを停止し、認可に基づく保存データの削除対応を行います。データ削除処理には人手での確認を含みます。

Google OAuthの連携はGoogleアカウントの接続管理から取り消せます。本ツール内の保存記録を削除しても、YouTube上に投稿された動画が削除されるわけではありません。YouTube上の動画削除はYouTube Studioなどから別途行う必要があります。

Google APIのポリシー

Google APIから受け取る情報はGoogle API Services User Data PolicyおよびYouTube API Services Developer Policiesを踏まえて取り扱います。
