アプリについてプライバシー利用規約

プライバシーポリシー

更新日：2026年11月11日

取得・利用する情報

所有者のGoogle OAuth同意に基づき、YouTubeチャンネルの情報、投稿する動画・タイトル・説明文・サムネイル、投稿後の動画ID・公開状態・処理状況を扱います。これらは投稿、結果確認、重複投稿防止に使用します。

保存・共有

認証情報と運用記録は、所有者が管理するアクセス制限付きの環境に保存します。投稿や記録の管理にGoogle/YouTubeおよび外部の保管サービスを利用します。収集した情報を広告目的で販売したり、公開サイトに非公開動画の情報や認証情報を掲載したりしません。

保持・削除・権限取消

運用に必要な記録を保持し、YouTube APIから取得したデータは適用されるポリシーに従い更新・削除の対象とします。保存情報の確認や削除のご希望は下記メールへお問い合わせください。Googleアカウントの連携管理から権限を取り消すこともできます。アプリ側の記録削除は、YouTube上の動画削除とは別です。

Google APIのデータ利用はGoogle API Services User Data PolicyおよびYouTube API Services Developer Policiesに従います。
